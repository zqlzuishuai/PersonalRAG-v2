# Rhine 剩余网页适配

用户已认可横屏重做，授权补齐剩余适配。保留 Vue、同源 API、既有业务页面与已认可的 SnapCard 几何，不涉及 OS 锁屏能力或公网发布。

## 已完成

- 竖屏、宽度 <1000px 或高度 <620px 使用自然滚动表单，原生字体与触控尺寸、安全区、短横屏布局。
- 从可见标本卡 DOM 矩形计算紧凑起点；认证后释放输入焦点并回顶；飞行中视口变化直接交接同一个资料库 DOM。
- 字形解码、分行警告和次数、跟随三维投影的引线与交点标识。减少动态效果、隐藏页面和卸载清理。
- 紧凑/粗指针入口使用低质量三维、30fps、DPR≤1.25。
- 修复无 GPU 投影时警告默认坐标，静态警告行在减少动态效果下全部可见。

## 证据与边界

19 项前端回归通过，构建通过。实际浏览器检查从 320px 至 1440px 的八组尺寸，无横向溢出；65 帧竖屏进入采样宽度保持 360px。飞行中旋转、减少动态效果重试、输入焦点与缩小视口、桌面引线均检查。320px 业务页面操作仅检查隔离示例 API 支持的展示和入口。

媒体及视口仿真已恢复，预览服务和交付标签保留。没有实机手机软键盘、真实数据库/模型/上传处理或公网验收。三维独立块的体积提示保留。独立复核因代理限额没有执行，本轮为自查加自动测试和浏览器证据。
