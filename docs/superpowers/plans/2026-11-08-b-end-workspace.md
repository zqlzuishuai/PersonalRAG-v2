## 设计与约束

来源 f56256e0a7432bd2d60d317eb33048f2c09df296，已读 SKILL.md 及 references/01–07。按 PageHeader→FilterPanel→DataSection 组织资料库，检索使用 Search List，独立详情支持可分享 URL。

浅灰绿画布、白色表面、深灰绿文字、松绿色主操作；14px 正文、20px 页标题、12px 辅助文案。列表时间右对齐，轻微边框，状态浅底深字，当前页数据数量不冒充全库统计。没有后端支持的批量操作、进度百分比或统计不伪造。

用成熟 Reka UI Dialog 原语封装 400px 小窗口与 600px 抽屉，保留焦点锁定、返回焦点和读屏标题。遮罩不关闭表单，脏数据离开确认，提交锁定退出。Lucide 统一工作区图标。资料快速查看保留列表，版本管理保留独立详情页；上传/移动用抽屉，简单创建/改名用小窗口，回收明确可恢复性。
