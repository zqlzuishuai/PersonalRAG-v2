## 使用

先把 02_bm25.sql 上传到 postgres 可以读取的位置，例如 /tmp/personalrag-v2/：

    sudo -u postgres /usr/pgsql-18/bin/psql -X -v ON_ERROR_STOP=1 -d personalrag_v2 -f /tmp/personalrag-v2/02_bm25.sql

使用管理员执行，勿使用 personalrag_v2_app。
脚本会检查库名，只创建缺失对象；现有配置和索引必须匹配，否则回滚报错。
它不会删除、重建现有索引，不会修改已有分词配置，不会改动用户资料。
首次创建索引会持有表锁；脚本最多等待锁 5 秒，单条语句限时 5 分钟。
现有可用索引无需为运行此脚本而重建。

## 在新服务器安装

操作系统中必须先安装与 PostgreSQL 主版本兼容的 pg_textsearch 和 zhparser。
按照 pg_textsearch 官方说明，把 pg_textsearch 加入 shared_preload_libraries 并重启 PostgreSQL；
请保留该设置原有的其他库。脚本不会安装系统包、编辑服务器配置或重启服务。
核对目标版本文档，不要只复制扩展文件跨 PostgreSQL 主版本使用。

数据库查询仍走 rag.searchable_chunks 和 user_transaction 的用户上下文。
本脚本不会放宽 RLS，也不直接向调用方返回未发布、已删除或其他用户的片段。
BM25 统计来自 chunks 整张表的索引，不是每个用户单独的语料统计。
