# PersonalRAG v2 SQL 交付计划

目标：生成用户手动执行的 PostgreSQL 18 建库、建表和验证脚本，不在云服务器执行。

1. 先编写事务回滚式验收 SQL，覆盖表存在性、跨用户 RLS/外键、根文件夹重名、原文版本不可变、处理结果发布、引用和回答串行化。
2. 使用本机缓存 pgvector 镜像，启动无网络、无端口映射、临时内存数据盘的独立容器；在空库运行验收 SQL，确认因缺少业务表失败。
3. 编写 `00_create_database.sql`：独立 owner/app/auth 角色、新库和连接权限；不提供预置密码，不触碰旧库。
4. 编写 `01_schema.sql`：十张表、复合外键、约束、索引、必要触发器、用户隔离策略和当前可检索视图。脚本在事务中一次性安装，拒绝错误库名和重复覆盖。
5. 编写 `README.md`：执行顺序、设置密码、用户上下文、原文目录、应用侧责任及运行验收脚本的方法。
6. 在临时容器执行全部脚本，确认验收事务回滚后不存在测试用户；验证重复建表失败且既有结构保持完整。保存简短验证结果，最后删除本次创建的临时容器。

范围不包含旧库迁移、真实用户创建、云端部署、LangChain 服务实现或原文数据上传。
